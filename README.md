# Toolbox Talk

365-day daily L&D practice app for a Head of L&D. One unique card per day, coins, daily rewards, a self-set reward shop, and gift codes.

1. Edit SECRET in index.html and gift.html (same value in both).
2. Push to a GitHub repo, enable Pages (Settings > Pages > main > root).
3. Keep gift.html for yourself: open it at your-link/gift.html to make gift codes, or delete it from the repo and run it locally.
